# C01-03 点乘不能代表完整SM2

## 输入

我的C程序有SM2曲线的kG和kPB点乘，保存两个点坐标，然后用点减法恢复明文。点乘都对了，能宣布SM2加解密实现完成吗？

## 实际答复

目前证据只能说明某条椭圆曲线点运算路径，不能宣布SM2公钥加密完成。还要知道曲线参数、所用版本、消息编码和密文布局。标准加密链不仅需要`C1=kG`、`S=kPB`，还需要合法公钥及余因子检查、规范坐标编码、`t=KDF(x2||y2,klen)`、t全零时重试、`C2=M xor t`、`C3=Hash(x2||M||y2)`。解密要验证C1、重建t、恢复M并验证C3，认证失败不释放明文。

你的“保存点坐标、点减恢复”更接近椭圆曲线点加式加密，不能凭曲线名称把它等同于SM2。包内第11章对应原书描述页161—163与实现页170—177，记录了同类缺口；这只是可见片段的判断，不能臆断未提供光盘工程中所有函数的行为。

请提供完整加解密链或其相关函数，再核具体编码和失败路径。验收至少覆盖正常向量、非法C1、C2/C3篡改、截断和t全零重试。当前没有运行你的程序，也没有新的标准SM2互操作结果。

## 路由与判定

C01正例；不调用小参数计算器冒充完整SM2。答复识别缺失链、将点运算与方案分开且不推测缺失源码。语义通过、边界通过、路由通过。
