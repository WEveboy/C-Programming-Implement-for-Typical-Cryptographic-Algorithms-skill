# C01-02 DES解密入口

## 输入

书里说密文解密前先逆初始置换。我按IP逆→倒序轮密钥Feistel→IP逆写了解密，这个顺序对吗？请给出能分辨两种入口的实例。

## 实际答复

该顺序不对。依据本章的加密网络`E=IP^-1∘F_K∘IP`，逆函数为`D=IP^-1∘F_K^-1∘IP`：输入密文先IP，再倒序轮密钥的Feistel，最后IP逆。原书印刷24页那句话与本章网络定义相冲突；IP逆表本身是正确对象，错误在把它放到解密入口。

本次实算新例：8字节key=`1a2b3c4d5e6f7081`，明文=`63616e676a693230`，独立库给密文=`ad9d3dc9ea5be9f8`。按正确IP入口解密得到`63616e676a693230`；把入口改IP逆得到`698e9b0069f17b60`。Python使用冻结DES位表独立写轮结构，并以独立库相同单DES映射作对照（TripleDES EDE的三个相同key退化为单DES），没有借用C审计可执行文件。见同目录脚本和JSON。

继续实现时固定数学第1位为输入最高位、C下标转换一次、16轮后的半部交换与子密钥逆序。此例支持入口顺序辨误，不代表完整文件格式、三重DES或当代安全选型已验收。

## 路由与判定

C01负责描述/实现差异，数值小例为可区分证据。已给出逆函数推导与不同实际输出，没有照抄错误文字。语义通过、边界通过、路由通过。
