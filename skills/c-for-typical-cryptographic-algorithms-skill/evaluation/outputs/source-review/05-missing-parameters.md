## 实际答复

目前无法给出可验证的提速实现：算法与原代码未知，也没有性能基线。先补最少信息：算法及版本/参数、相关C函数、目标CPU与编译器、代表输入长度，以及衡量密钥设置、单块延迟还是批量吞吐。

现在可以建立验收契约：固定消息编码、端序、错误返回和随机数生命周期；保留易审查基线；冻结正确性向量及边界；仅在逐输出和必要中间状态一致后计时。计时分开密钥设置、核心计算与I/O，多次运行记录编译参数和分布。不能把减少轮数、固定随机k或删除认证当作等价优化。

等拿到算法后，来源审查先确定本书描述/实现是否对应，再把实际C差分与优化交给C03。本次没有代码修改、实际计时或性能提升结果；我不会假定“那个算法”就是AES。
