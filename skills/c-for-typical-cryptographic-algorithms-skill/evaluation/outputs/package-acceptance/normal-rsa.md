# 实际模型答复：新的RSA教学复算

请求：使用这个Skill复算p=7、q=19、e=5、消息整数36，说明结果及边界。

我按副本内SKILL的精确复算路径读取有限实例卡与RSA章节，运行副本的`scripts/exact_instance.py`，输入为：

```json
{"algorithm":"rsa","p":7,"q":19,"e":5,"message":36}
```

本次得到n=133、φ(n)=108、私钥指数d=65、密文120，解密恢复36。7与19为不同素数，gcd(5,108)=1，0≤36<133，且5×65=325≡1 mod108。加密也可逐步核算：36² mod133=99，36⁴ mod133=92，36⁵ mod133=120。

工具退出0，实际输出：

```json
{"status":"ok","result":{"n":133,"d":65,"ciphertext":120,"recovered":36}}
```

这是本次新合成教学输入，不是原书实例。算法依据为包内第6章研读记录（底本印刷97—113页，PDF110—126页）；本次没有读取原PDF。结果只验证整数原语，不代表完整RSA加密编码、C实现或生产安全。
