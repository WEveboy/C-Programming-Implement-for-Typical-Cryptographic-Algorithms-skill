# 实现时容易混淆的术语

| 术语 | 本包的精确含义与判别 |
|---|---|
| 模加 | ZUC31位素数模加与uint32自然回绕是两个运算 |
| 状态布局 | AES列优先、Keccak lane坐标与字节端序各自固定；不能只改两端 |
| 密钥扩展 | 从主密钥得到轮密钥；与数据轮变换分别核验 |
| 单位元群 | 有乘法逆的剩余类；Paillier随机r必须属于Z_n* |
| L函数 | L(u)=(u−1)/n，调用前要求精确整除，不是整数截断 |
| 中心提升 | 将模q类选为围绕0的整数代表，再做后续模p；区间端点必须固定 |
| 循环卷积 | 在Z[x]/(x^N−1)中下标按N回绕，不是零填充线性卷积 |
| 群阶/子群阶/域模数 | 三个不同对象；ECC点坐标模p，标量按指定子群管理 |
| 无穷远 | 椭圆曲线加法单位元，用null表示；不是任意坐标(0,0) |
| 消息编码 | 文件到整数/位串/曲线点的可逆映射，不能从算术正确自动推出 |
| KDF/认证链 | SM2描述所需步骤；共享点或点加密文本身不足以替代 |
| 码距d/纠错t | 唯一纠错要求d≥2t+1；(7,4,3)的3是距离，t=1 |
| 海绵rate/capacity | 输入输出只经过rate，capacity参与内部状态；域分离另行绑定 |
| Keccak/SHA3 | 本包将旧0x01域与正式字节对齐SHA3的0x06域分别命名 |
| 原例/合成演练 | 原书可定位数据与新设计输入分别标注，不能相互冒充 |
| 标准向量/差分oracle | 固定来源输出与独立库计算分别记录；往返不是兼容性证明 |
| verified | 仅表示当前任务契约有相应证据，不意味着完整方案或生产安全已验收 |
