# 把算法描述变成可靠C实现，要守住什么

本书由固定宽度的流/分组密码进入整数、环、曲线和编码，最后回到Hash状态机。共同任务是把数学对象变成机器表示，再把消息表示和程序接口补完整。文件能加解密只是其中一项证据。

ZUC最容易错的是两种模加、31位高半字与初始化时序；DES是数学位号、初始置换和逆序子密钥；AES是列优先、域乘法及首末轮；SM4是L/L′和末四字反序。新实现应先固定load/store与整数宽度，之后才考虑查表或展开。

MH的贪心恢复依赖超递增和模数大于总和。RSA的整数恢复可以对所有剩余类成立，但整数原语不提供消息方案。Paillier必须先确认随机数是单位元，L是精确整除且结果可逆。教材NTRU先在整数上理解卷积界，再解释模q中心提升，不能只保留最后一次模p。

ElGamal的正确性来自两个共享幂相等；同一k跨独立密文重用会暴露明文比值。ECC进一步要求消息类型明确：域元素乘共享横坐标与点消息加共享点是两种方案。SM2还包含KDF、密文认证与失败处理；只有点乘和点加不足以构成SM2。McEliece的矩阵消去证明依赖满秩、可逆矩阵、置换和纠错半径，玩具小码枚举不能代替Goppa译码器。

Hash相似的Init/Update/Final接口隐藏了不同计数器、padding、输出和域分离。BLAKE旧轮数与最终版分开；Grøstl填充写块计数；JH不能把本次长度直接覆盖累计长度，也不能用填充赋值覆盖有效消息位；Keccak旧域和正式SHA3分别命名；Skein要保留真正末块并完成配置/消息/输出三类UBI。版本、位串定义和末块边界都是算法身份的一部分。

因此本技能把来源审查、有限精确计算和C差分分成三张可组合能力卡。书例是解释机制的起点，新输入和拒绝路径才能检查实现契约；独立oracle和中间轮状态帮助定位两套互逆错误共同掩盖的问题。等价性成立之后再测性能，并分别记录密钥设置、核心吞吐和I/O。没有完整源码、真实计时或侧信道证据时，留下具体缺口，不用成功截图替代。
