# 可见代码逐单元复核与来源缺口结算

本表覆盖13章“核心代码”可见片段。页码均为印刷页，PDF加13。`reviewed-fragment`表示已经分析页面所示运算和依赖，不表示获得了作者完整工程；本文不把缺失的函数体用重建代码冒充。独立C审计核位于reference-c，仅用于检验数学表示与常量。

## 第1–4章：固定宽度核心与文件包装

| 来源/单元 | 输入到输出与不变量 | 逐项裁决 |
|---|---|---|
| 1，15–18：main、密钥/IV文件读取 | 16个字节值→初始化参数 | 文件打开、读数和0…255范围需检查；`%u`对应的中间变量类型须匹配，不能直接写uint8指针 |
| 1，16–18：4字节组装/尾组 | 原始字节→32位消息字→密文文件 | 左移前无符号转换；尾长独立保存；读失败不能当合法零字节；现有缓冲容量宏未给出完整定义 |
| 1，18：Initialization/GenerateKeystream/decrypt调用 | key/IV/字数→输出 | 页面只见调用，不能验证被调状态机源码；独立核按32轮+丢弃轮验证前三组外部测试数据 |
| 2，38：Usage | 参数错误→用法文本 | 不属于DES核；字符密钥与原始64位密钥须另定编码 |
| 2，38–39：FileIn | CFile→分配的缓冲与长度 | MFC/C++；调用方所有权、异常、int长度窄化、new失败和MAX_FILE均为接口前提 |
| 2，39：FileOut | 指针/长度→磁盘字节 | CFile依赖；写失败传播和合法长度未形成完整契约 |
| 2，39：CheckParse | argc/argv→bool | 最多8字符不足以约束恰8字节；先验argc后才能访问argv[3]；未展示完整加密/补齐核 |
| 3，59–60：SetNbNkNr | keySize→Nk/Nr | 只接受三档；未知枚举必须拒绝，不能留未初始化参数；Nb固定4 |
| 3，60–61：KeyExpansion | 主密钥→4(Nr+1)字 | 核查Nk分支、Rcon下标与AES256额外SubWord；缓存需容纳240字节；动态temp的所有权需修正 |
| 3，61：RotWord/SubWord | 一个字→一个字 | 每次new会带来所有权/泄漏问题；改为原地或栈数组；SubWord索引高低半字节应等价于直接字节索引 |
| 3，62：Cipher | 16字节→16字节 | 标准列优先；初始AddRoundKey，中间Nr−1轮，末轮省MixColumns；读写布局不是任意可互换 |
| 3，62–63：InvCipher | 密文→明文 | Nr反向到1；先逆移位/逆S，再加对应轮密钥，再逆列混合；首尾轮独立 |
| 3，63：AddRoundKey | state+round→state | 密钥偏移16*round+4*col+row；round范围0…Nr |
| 3，63–64：SubBytes/InvSubBytes | 每字节→代换字节 | 逆变换内层循环条件错用j，已回原页确认；这是代码缺陷，不是OCR误判 |
| 3，64–65：ShiftRows/InvShiftRows | 行循环置换 | 先完整复制临时状态再覆写；逆移位取模不能用负C余数直接下标 |
| 3，65–67：MixColumns/InvMixColumns | 每列域线性变换 | 固定GF(2^8)，正逆矩阵对拍；不能把普通乘模256当域乘 |
| 3，67：gfmultby01/02/03/09/0b/0d/0e | 字节→域乘结果 | 左移后截断；乘2约减0x1b，复合常数由乘2和异或构建；全字节测试可完成有限核验 |
| 4，79：SM4Crypt | Input/rk→Output | 每次展开四轮并依次更新，循环步长4；尾四字反序；直接uint32指针强转有端序/对齐/别名前提 |
| 4，79–80：SM4KeyExt | Key/flag→rk | FK预白化，CK顺序，L′旋转13/23；解密仅倒序rk，不能换成L；64个书例中间值已与独立核一致 |

## 第5–9章：数论、随机数与大整数

## 第13章：每个 Update/Final 分别判定

| 单元与位置 | 运作与裁决 |
|---|---|
| blake256_init，205 | 指定8个IV字并清计数/缓冲；头文件与state定义缺失，不等于完整压缩核 |
| blake224_compress，205 | 只见入口/局部声明，未给完整G及轮循环；轮数版本必须从配套源码确认 |
| blake224_init，205 | 224族有独立IV，不只是256输出截断；本轮逐项保存IV来源与版本 |
| blake224_update，205–206 | 参数单位为bit；跨块增加512并进位，data前移字节数与bit剩余量分开 |
| blake224_final，206–207 | buflen=440与单/双padding块分支；减计数操作依赖nullt语义，不能仅替换padding字节 |
| blake224_hash，207–208 | 外壳将inlen字节乘8；必须拒绝超出bit计数范围的长度，不能靠乘法回绕 |
| Grøstl Init，210 | IV编码输出长度；32位存储端序处理与状态宽度绑定 |
| Grøstl Update，210–211 | buffer、完整字节与末有效位分别维护；非整字节分片的后续行为需定义；Transform未展示 |
| Grøstl Final，211–212 | padding填块计数，进位链和输出变换不可省；摘要从尾部截取 |
| Grøstl Hash/crypto_hash，212 | 一次性包装与字节到bit换算；不从函数名推断支持大于32位的长度 |
| JH Init，214–215 | 1024位状态、摘要长度前缀、零块派生IV；F8缺完整体 |
| JH Update，215–216 | databitlen被本次值覆盖，尾块缓冲重置；作为流式多次调用不满足累计语义 |
| JH Final，216–217 | 整块/非整块分支各自写末位与长度；只写64位长度需要明确支持上限；输出偏移100/96/80/64 |
| JH Hash，217 | 仅接受四档长度；一次性包装不等于增量Update通过 |
| keccakf，220 | 五步置换：θ列、ρπ搬移、χ整行旧值、ι轮常量；完整常量数组在配套文件中，页面未逐字给出 |
| keccak，220–221 | byte计数rate=200−2*mdlen；直接uint64装载有端序/对齐前提；0x01属于旧Keccak域，不是正式SHA3的0x06 |
| Skein_256_Init，225 | 先CFG再MSG，包含输出长度/树参数；不是直接赋IV就结束 |
| Skein_256_Update，225–226 | 用>而非>=保留末块以供Final标记；改变判断会改变整块消息结果 |
| Skein_256_Final，226–227 | 最后真实消息字节数传给UBI；OUT计数器逐块产生摘要；恢复X不能漏 |
| Skein_256_Output，227 | 输出域分离与配置定义依赖skein头文件/Process_Block；缺少它们无法据页面独立编译 |

## 结算

每个可见单元已有去向与下一实现条件。书中未给出的函数体、表构造、宏与工程不能靠猜测转成“作者源码已复现”。ZUC/DES/AES/SM4/海绵的独立核只用于收敛数值和表示问题；它们不补足公钥消息封装、光盘工程、旧版Hash完整源码或生产级安全验收。

本次完成的是**现有输入可支持的片段审读结算**。缺失源码若以后补齐，需要按依赖重新核验对应单元；不影响已冻结的转写数据和有限计算证据。
