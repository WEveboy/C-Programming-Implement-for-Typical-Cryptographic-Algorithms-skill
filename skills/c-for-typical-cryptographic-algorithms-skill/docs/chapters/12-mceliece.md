# 第12章：McEliece 的译码能力不能从矩阵乘法测试中推定

来源：印刷页183–198 / PDF页196–211；描述§12.1，实现§12.2（页188起）。

## R：对象分离

本章先介绍二元Goppa码McEliece，再讨论RS码、秩度量（原文F距离）和Niederreiter变体。汉明重量、秩及译码假设不同，不能统称为一套已验证方案。

## I：基础构造

行向量约定下G为k×n生成矩阵，S为k×k可逆混淆矩阵，P为n×n置换矩阵；公钥G′=SGP。明文m长k，采样长度n且重量≤t的错误e，密文c=mG′+e，所有二元加法为异或。

解密先cP^−1=mSG+eP^−1。置换保持汉明重量，因此私有译码器仍能纠正至多t错误，输出信息向量mS，再乘S^−1恢复m。若译码器只输出码字，必须另做信息提取，不能直接把码字当mS。综合`cP^−1 H^T`给出错误综合，但它本身不唯一提供信息向量。

标准置换有P^−1=P^T；广义置换（单项矩阵）只有保持汉明重量这一结论仍成立，逆矩阵通常不是转置。改用RS/秩度量需分别论证结构隐藏和攻击抵抗，公钥数量多或穷举代价大不是安全证明。

## A1：书例和代码

页188–190的(7,4,3)小码是演示一次纠错的矩阵例；其中第三参数3是最小距离，纠错能力为1，不能误填t=3。手抄G/S/P后可全枚举16个明文和每个0/单比特错误，以最近码字译码作教学见证。这个穷举译码器不是大参数Goppa快速译码。

页191–194仅展示`sqsnsex / sqrtsex / funsex`等辅助函数，以及`mce_encode / mce_decode`调用。g_gop、有限域表、码构造、初始化和完整译码接口均需配套工程；静态工作数组还带来重入/并发限制。页194按`clock()`除1000处理时间，应改用CLOCKS_PER_SEC或单调时钟。

书中n=1024,k=654,t=37，公钥全矩阵按位紧凑存储需654*1024/8=83712字节，与页194一致。这验证的是存储算式，不代表该参数的当前安全性，也不证明正文k=n−mt在所有Goppa码下总为等号；通常需实际求秩。

## A2：触发

用于矩阵方向、置换逆、信息提取与译码接口的设计，以及教学例复算。请求现代Classic McEliece时应另绑定具体版本、参数和KEM流程。

## E：C 实现路线

先定义GF(2^m)的不可约多项式、基、位序；构造G/H并检查GH^T=0、秩、S逆与P置换性。用显式位向量完成mG′，验证错误生成器精确重量。小例全枚举；大参数用独立译码实现/KAT做交叉核验，必须包含不可纠正和畸形输入的失败行为。

优化可做矩阵按机器字打包、预计算表及译码核优化，分开测密钥生成、编码、译码和公钥内存。不能把移除随机错误或用遍历最近码字冒充生产级译码优化。

## B：边界

本次未恢复Patterson等大参数译码器、完整Goppa构造或KEM；RS/秩度量变体作为参考/待核，不作安全晋级。小码矩阵测试不支持全族安全或通用译码声明。
