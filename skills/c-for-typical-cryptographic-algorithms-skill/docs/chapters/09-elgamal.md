# 第9章：ElGamal 的每次随机数必须属于每次加密

来源：印刷页135–145 / PDF页148–158；描述§9.1，实现§9.2（页137起）。

## R：范围

本章同时介绍有限域加密和一组签名公式，核心代码展示大整数与文件序列化。两个用途的参数、随机数条件及验收必须分别建档。

## I：算法描述

在明确有限循环群G中固定生成元g，私钥a、公钥y=g^a。明文必须为群元素m。加密独立采样k，输出(c1,c2)=(g^k,m*y^k)；解密m=c2*(c1^a)^−1。正确性只用群律：g^(ka)=y^k，乘逆后抵消。

保密不只依赖“离散对数难”这句概括；具体群、消息空间和攻击模型都重要。对均匀消息的恢复、语义安全及选择密文安全不能互换。本项目不继承页136把不同困难性与安全模型直接等同的表述。

页135签名采用`r=g^k mod p`、`s=k^−1(H(m)+a*r) mod(p−1)`，故必须要求gcd(k,p−1)=1。以y=g^a统一符号后，验式为`r^s=g^H(m)*y^r mod p`：由ks≡H+ar (mod p−1)及费马定理直接推出，说明加号变体在此条件下代数自洽。加密中的k则不需要这个逆模p−1条件。此处“DSA”标签不成立：[历史FIPS186-4 §4.6–4.7](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.186-4.pdf)使用素数阶q子群、r再模q、s模q及不同验签式；该文档已归档，仅用作同年代定义对照。不能将教材公式直接实现为DSA。

补测以合成参数p11/g2/a5/k7/H6得到r7/s3，并在该小群全部40个合法k/摘要余数上验证加号等式；k2因gcd(2,10)≠1拒绝。它只验证代数恒等，不证明此变体的签名安全性。

## A1：实例与代码发现

书例p=11,g=2,a=5,y=10，m=6,k=7；输出(7,5)，乘共享秘密的逆恢复6。脚本复算只验证该小例。

页138在文件循环之前调用一次`k.GeneratePrime()`，页139循环里重复用k计算两个密文分量。原页核对后可定位为随机数生命周期问题：对于两个非零消息若复用k，c1相同，c2比值泄漏明文比值；一个明文已知时可恢复另一明文。不能因文件最终能解密而接受这种封装。

页139–141把BigNum的底层32位字直接写文件，并在末尾保存cnt/last_read。读取却通过多次尾部seek和逐字节重组，必须重新建立“写入格式→读取格式”的双向规格；不能假定主机内存布局就是跨平台文件格式。生成一个随机数g也不等于证明其为所需群生成元。

## A2：触发

检查乘法群概率加密、重复nonce后果、大整数序列化时使用。签名、DSA和椭圆曲线版本分别路由。

## E：C 移植契约

先固定群及元素编码，检查公钥、c1和消息的群归属；每个独立加密样本采样新k。把大整数装卸转换为固定端序字节串，拒绝截断、非法长度和越界计数。建立正常书例、不同k同消息、相同k两消息反例、m=0/非群元素、非法c1及尾组测试。

性能改进优先共享大整数模约减、固定基预计算和批量I/O；随机数重用不能算优化。页144–145约40/123/197秒是教材历史环境中的文件实验，不能与其他章节不同硬件/参数结果直接排名。
