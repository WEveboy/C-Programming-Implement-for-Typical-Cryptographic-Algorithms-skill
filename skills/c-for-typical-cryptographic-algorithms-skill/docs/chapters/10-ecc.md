# 第10章：两种 ECC 加密的消息空间和零值边界不同

来源：印刷页146–160 / PDF页159–173；描述§10.1，实现§10.2（页150起）。

## R：本章的两个契约

作者先介绍域元素乘共享点横坐标的“初始ECC”，再介绍明文嵌点的加法ElGamal。它们共享点运算，但消息空间和失败条件不同。页152–155两段文件代码相似，不能仅凭标题判断实现了哪一个公式。

## I：数学描述

素域短Weierstrass曲线满足`y²=x³+a*x+b modp`，p>3且4a³+27b²≠0。域参数p、曲线群阶#E、基点阶n和余因子h不能混同；h应为#E/n的精确商。私钥d∈[1,n−1]，公钥Q=dG。

“初始ECC”取新k，R=kG，S=kQ=(x,y)，输出(R,c=m*x modp)；收方由dR得到S并乘x的逆。若S为无穷远或x=0，逆元不存在，应重采样或拒绝。m为域元素，m=0总给出c=0，不能把这一教学方案作为通用机密文件加密标准。

嵌点式把m可逆编码为曲线点M，输出(R=kG,C=M+kQ)，解密M=C−dR。难点是“可逆编码”，任意字节拼成的(x,y)一般不在曲线上；单凭坐标能装下数据不能认为已完成嵌点。

仿射点加需分支处理无穷远、P=−Q、倍点y=0；其余用域逆计算斜率。倍点斜率为(3x²+a)/(2y)，异点相加为(y2−y1)/(x2−x1)。标量乘可用二进制倍加验证，再研究窗口/坐标变换。必须先验证输入点和子群，再使用秘密标量。

## E：实现路线

建立`field / point / scalar / encoding / scheme`五层。参考点运算采用清楚的无穷远标志；序列化长度固定且坐标规范化。测试群单位元、负点、倍点、nG=O、错误曲线点、x=0和原例。嵌点必须独立做全可表示输入的往返测试。

优化可比较Jacobian坐标、固定基窗口和批量求逆，记录预计算空间与摊销次数。秘密标量依赖的分支和索引另做侧信道检查。曲线与基点不能为追求计时随意缩小。
