# 第2章：DES 的可逆性来自 Feistel，移植难点在位序

## I：算法描述

64位分组经过IP分为L0/R0。第i轮为`Li=R(i−1)`、`Ri=L(i−1) XOR f(R(i−1),Ki)`。最后输入逆IP的是`R16 || L16`。这次交换使解密仍使用同一网络，只需倒序使用子密钥。

f先把32位R经E扩展为48位，与Ki异或，分为8组6位。每组的外侧两位确定S盒行、中间四位确定列，得到8×4=32位，再经过P。E的重复位与P共同促成跨S盒扩散，S盒提供非线性；固定IP不是独立的保密来源。

64位输入密钥包含8位奇偶校验，有效密钥56位。PC-1去校验并重排为两个28位半部，按`1,1,2,2,2,2,2,2,1,2,2,2,2,2,2,1`循环左移，PC-2生成48位子密钥。半部必须截回28位；主机整数的32位旋转不等价。

本章讨论互补性、4个弱密钥与6对半弱密钥。这些可作为额外代数测试，不能替代标准向量。三重DES需显式区分EEE/EDE以及两密钥/三密钥；总密钥材料长度不直接等于有效安全强度。

## E：可执行实现路线

1. 先建立“第1位是输入最高位”的逐位置换基准；表项从1起，C数组从0起，只转换一次。
2. 分别实现64→64、64→56、56→48、32→48、32→32的置换；中间值用无符号整数，避免48位值被32位截断。
3. 验证IP逆复合恒等、S盒6位输入全枚举、密钥移位和16轮状态。对标准向量比较密文，再检查解密。
4. 文件层测试0/1/7/8/9字节和原文尾部零；长度与padding显式编码。纯C用`FILE*`与显式缓冲长度替换MFC。
5. 优化可比较位表、合并S/P表和位切片；每种实现与位级基准逐分组对拍。三重DES另验顺序和退化情形。
