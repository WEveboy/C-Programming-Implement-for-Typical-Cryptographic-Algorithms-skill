# 第8章：NTRU 解密最容易漏掉的是中心提升

来源：印刷页125–134 / PDF页138–147；描述§8.1，实现§8.2（页128起）。

## R：范围

本章是截尾多项式环上的教学NTRU加密，不是任何后来标准化KEM的完整实现。来源本身页125概括安全性“等价”，页128又承认没有证明等价最短向量问题；后者限定了可继承的结论。

## I：对象与算法

在R=Z[x]/(x^N−1)中用长度N系数向量表示多项式，乘法为循环卷积。L(a,b)指定恰有a个+1和b个−1的稀疏多项式集合。选择f在模p和模q的商环中都可逆，记fp/fq；h=fq*g modq，公开(N,p,q,h)。

加密取小随机r，`c=p*r*h+m modq`。解密先算a=f*c modq，将每个系数提升到以0为中心的代表，再算m=fp*a modp。正确性依赖真实整数卷积`p*r*g+f*m`的系数落在该代表区间；否则模q折叠后再模p一般无法恢复。

中心提升不是可省略的展示格式。页125、129的简短解密描述没有展开这一条件；实现必须把提升区间（例如偶q用[−q/2,q/2)）及边界定清。q通常为2的幂，不能直接当域用任意有限域逆算法；求逆失败要重新采样f。

## A1：书例与文件程序

页128–129给N=5,p=3,q=16；f=x^4+x−1、g=x^3−x，fp=fq=x^3+x²−1（分别按模数解释），h=−x^4−2x³+2x+1，m=x²−x+1，r=x−1。密文为−3x^4+6x³+7x²−4x−5。见证脚本用精确循环卷积验证逆元、公钥、密文和中心提升恢复。首稿误读了最高项负号，已回PDF页142校正并保留测试初稿。

页130–131的代码主要是`fread / binary / Encode / Decode / recover`文件包装，含固定107系数及2字节读写假设，不是多项式求逆与译码核的完整实现。标准C中`fread`返回元素数，若每元素2字节便不能直接解释成字节数；文件格式必须显式记录元素位宽、端序、块数与最后一块有效长度。

本章讨论穷举、相遇、重复消息和格规约攻击；稀疏私钥分布是攻击条件的一部分。页133的性能与安全评论只保留为历史背景，不从N变大单独推出安全。

## A2：触发

需要循环卷积、双模逆元、解密失败分析或教材参数复现时读取。请求现代NTRU类KEM时，应另选具体版本及封装规范。

## E：实现与优化

先用int64中间累加的O(N²)循环卷积，计算N*系数界以检查溢出。逐项核`f*fp=1 modp`和`f*fq=1 modq`；按中心提升契约解密，再编码输出。测试基准例、全零/基向量、小参数随机明文、不可逆f及明确引发中心提升失效的样本。

优化比较稀疏卷积、Karatsuba及适配模数的变换法；不能假设任意q都直接支持所需NTT。基准与优化版逐系数比较，并统计解密失败而非仅吞吐。随机r、参数族和消息编码不得在优化时偷偷更改。
