# 第5章：MH 用模乘隐藏超递增结构，正确性依赖“不绕回”

来源：印刷页85–96 / PDF页98–109；描述§5.1，实现§5.2（页89起）。

## R：本章任务

建立私有易解子集和，通过可逆模乘生成公开背包，再用逆模乘恢复易解问题。本章还讨论低密度攻击、Rabin组合、分段与重复加密；这些扩展均不自动获得基础算法的安全性结论。

## I：算法描述和证明条件

选择正整数超递增序列b：每个b[i]大于其所有前项和。选N>sum(b)，再选gcd(w,N)=1的w，计算a[i]=w*b[i] modN。公开a，私钥至少保存b、N和w的逆。明文为n个二进制位，密文是普通整数和`c=sum(m[i]*a[i])`，不是任意先模N的值。

解密令`s=w_inverse*c modN`。由于真实子集和在0…sum(b)而sum(b)<N，s正好是真实子集和，不只有同余信息。然后从最大b开始：若b[i]≤s则置m[i]=1并减去它，否则置0。超递增保证该贪心恢复唯一。结束剩余s必须为0，否则输入不符合契约。

模数太小会把多个真实和折叠，乘数不互素则无法求逆，序列不超递增会破坏贪心证明。书中页91通过`N=2*b_last+随机正数`生成N；对超递增序列这能保证N>sum(b)。这一正确性条件和随机质量是不同问题。

## A2：适用

用于超递增贪心、扩展欧几里得和整数范围检查的教学实验，以及分析为什么易解结构隐藏后仍可能被恢复。

## E：C 实现入口

输入先检查n、全部正项、前缀和、N上界及gcd；所有加乘先检查溢出，或统一用大整数层。算法核接受位数组并返回大整数；文件层负责位序和最后一组位数。分开实现`keygen / subset_sum / inverse_map / greedy_decode`。

验收包括所有2^n个小参数明文、全0/全1、非超递增输入、不可逆w、N≤sum(b)、无解密文。优化先看缓冲序列化和gcd/模乘，不能用缩短序列或固定随机种子伪称等价加速。

## B：安全边界

书中开篇已承认基础MH的结构攻击。一般子集和困难不推出该特定公钥分布安全；提高密度、分段或重复加密也没有在本项目取得安全证明。保持历史研究用途，不将参数生成演示升级为部署能力。
